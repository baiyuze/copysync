CopySync / Quick start

Quick start

Install the app, set up a server, and pair your computers. The first time takes about ten minutes; after that, copying just syncs.

  1. Install the app
  2. Set up a server
  3. Enter the address
  4. Pair

Step 1

Install the app on each computer

One on every computer you want to sync. Macs and Windows PCs mix freely.

Mac

  1. Download CopySync.dmg, open it and drag CopySync into Applications.
  2. Open it from Applications.The first time, macOS says it can't verify the developer: go to System Settings → Privacy & Security and click Open Anyway near the bottom.
  3. Click Turn on background sync, and allow clipboard access when macOS asks.
Download for Mac

Windows

  1. Run CopySync-Setup.exe; no administrator rights needed.If you see "Windows protected your PC", click More info, then Run anyway.
  2. Open CopySync and click Turn on background sync. After you close the window it keeps running in the notification area.
Download for Windows

Step 2

Set up a server

Your computers find each other through it; nothing you copy is stored there. There's no public server, so pick the option that fits:

No public IP needed Both computers on one network

On your LAN

At home or in the office, on the same Wi‑Fi or wired network. Run the server on one of your always-on Windows, Mac or Linux computers with a single script.

LAN guide → No public IP needed One at home, one at the office

LAN + Tailscale

The server stays at home. Install Tailscale on each computer and they act as if they shared a LAN, so your laptop keeps syncing wherever you take it.

Tailscale guide → Needs a public IP You have a public server

Cloud server

A Linux VM with a public IP; the smallest one is enough. Every computer connects to it directly, with nothing else to install.

Setup steps →

When it's installed, the script prints an address like ws://192.168.1.20:8787/signal. You'll need it in the next step.

Step 3

Enter the server address on each computer

  1. Open Settings

    Open CopySync on each computer, including the one running the server, and go to Settings.

  2. Enter the address

    Under Signaling server, enter the address from the previous step and press Return or Enter.

  3. Check the status

    When Connection shows a green Connected, that computer is ready.

Stuck at Not connected? See the questions.

Step 4

Pair your computers

Pair each two computers once, and you're done.

  1. On one computer, open Devices and click Add device. It shows a 6-character code, valid for 5 minutes.
  2. On the other, click Add device too, switch to Enter a code and type it in.
  3. Both screens show the same two fingerprint lines. Check them character by character, then confirm.This stops anyone in the middle from posing as your device. Don't skip it.

Now copy something.

Copy text, an image or a file on one computer and press ⌘V or Ctrl+V on the other. Everything copied on either side is in the history.
