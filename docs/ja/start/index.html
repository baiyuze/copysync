CopySync / はじめかた

はじめかた

アプリを入れて、サーバーを用意し、2 台をペアリングします。最初の設定は 10 分ほど。そのあとはコピーするだけで同期されます。

  1. アプリを入れる
  2. サーバーを用意
  3. アドレスを入力
  4. ペアリング

ステップ 1

各コンピューターにアプリを入れる

同期したいコンピューターすべてに入れます。Mac と Windows の組み合わせも自由です。

Mac

  1. CopySync.dmg をダウンロードして開き、CopySync を「アプリケーション」にドラッグします。
  2. 「アプリケーション」から開きます。初回は「開発元を検証できません」と表示されます。「システム設定 → プライバシーとセキュリティ」を開き、ページ下部の「このまま開く」をクリックします。
  3. 「バックグラウンド同期を有効にする」をクリックし、クリップボードの読み取りを聞かれたら許可します。
Mac 版をダウンロード

Windows

  1. CopySync-Setup.exe を実行します。管理者権限は要りません。「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。
  2. CopySync を開き、「バックグラウンド同期を有効にする」をクリックします。ウィンドウを閉じても通知領域で動き続けます。
Windows 版をダウンロード

ステップ 2

サーバーを用意する

2 台はサーバーを通じてお互いを見つけます。コピーした内容がそこに保存されることはありません。公開サーバーはないので、状況に合うものを選んでください。

グローバル IP 不要 2 台が同じネットワークにある

LAN に置く

家や会社で、同じ Wi‑Fi か有線ネットワークにつながっている場合。電源を入れたままの Windows・Mac・Linux のどれか 1 台で、スクリプトをひとつ実行するだけです。

LAN での設置手順 → グローバル IP 不要 1 台は自宅、1 台は会社

LAN ＋ Tailscale

サーバーは自宅に置いたまま。各コンピューターに Tailscale を入れれば同じ LAN にあるのと同じように扱えて、ノートパソコンを持ち出しても同期が続きます。

Tailscale での手順 → グローバル IP が必要 公開サーバーがある

クラウドに置く

グローバル IP を持つ Linux のクラウドサーバー。最小構成で足ります。すべてのコンピューターが直接つながり、ほかに入れるものはありません。

設置手順 →

インストールが終わると、スクリプトが ws://192.168.1.20:8787/signal のようなアドレスを表示します。次のステップで使います。

ステップ 3

各コンピューターにサーバーのアドレスを入力

  1. 設定を開く

    各コンピューターで CopySync を開き、「設定」に進みます。サーバーを動かしているコンピューターも同じです。

  2. アドレスを入力

    「シグナリングサーバー」に前のステップで表示されたアドレスを入力し、Return か Enter を押します。

  3. 状態を確認

    「接続状態」が緑の「接続済み」になれば、そのコンピューターは準備完了です。

「未接続」のままならよくある質問をご覧ください。

ステップ 4

2 台をペアリングする

2 台ごとに一度ペアリングすれば、あとは何もする必要はありません。

  1. 一台で「デバイス」を開き、「デバイスを追加」をクリックします。5 分間有効な 6 桁のコードが表示されます。
  2. もう一台でも「デバイスを追加」をクリックし、「コードを入力」に切り替えて入力します。
  3. 両方の画面に同じ 2 行の指紋が表示されます。1 文字ずつ照合して一致していれば確定します。途中で誰かがあなたのデバイスになりすますのを防ぐ手順です。省略しないでください。

コピーしてみましょう。

一台でテキスト、画像、ファイルをコピーし、もう一台で ⌘V か Ctrl+V を押します。どちらでコピーしたものも履歴に残ります。

困ったときは：LAN のよくある質問 · Tailscale のよくある質問 · 問題を報告
